## Asking a question

1. Search [existing issues](https://github.com/lazylib/ntfy/issues) and
   [discussions](https://github.com/lazylib/ntfy/discussions) first.
2. If you don't find an answer, open a new **Question** issue using the
   provided template.

## Filing a bug

Use the **Bug report** issue template. Include:

- a minimal reproduction
- your `go version`
- the package version (commit SHA or tag)

## Commercial support

This is a community-maintained package. No commercial support is
offered. If you need an SLA, vendor this package or fork it.
